# SAMWOO 디자인 시스템

## 목적

삼우 사내 서비스는 사용자가 업무를 빠르게 이해하고 다음 행동을 확신할 수 있어야 합니다. 표준은 장식적인 통일보다는 정보 구조, 일관된 상태, 브랜드 신뢰를 만드는 데 집중합니다.

## 디자인 원칙

1. **업무 흐름 우선:** 첫 화면에서 현재 위치, 핵심 정보, 다음 행동을 찾을 수 있어야 한다.
2. **상태를 명확하게:** 색상과 텍스트를 함께 사용하고, 오류에는 복구 방법을 제공한다.
3. **익숙한 구조:** 상단 브랜드 영역, 좌측 작업 내비게이션, 명확한 콘텐츠 계층을 유지한다.
4. **밀도에 목적 부여:** 관련 정보는 가깝게, 서로 다른 작업은 충분히 분리한다.
5. **모든 화면에서 완성:** 데스크톱을 축소하지 말고 모바일의 우선순위에 맞게 재배치한다.

## 브랜드 자산

| 파일 | 사용처 |
| --- | --- |
| `samwooeleco-favicon.png` | 브라우저 파비콘, 기본 서비스 아이콘 |
| `footer_logo-light.png` | 밝은 배경의 SAMWOO 워드마크 |
| `footer_logo-dark.png` | 어두운 배경의 SAMWOO 워드마크 |

로고는 원본 비율을 유지하고, 색상 변경·필터·왜곡·효과를 적용하지 않습니다. 테마별 전환은 `BrandLogo` 컴포넌트를 사용합니다.

## 색상

색상은 `src/styles/tokens.css`에서 관리합니다. 원시 색상값을 컴포넌트에 직접 반복하지 않습니다.

| 역할 | 라이트 | 의미 |
| --- | --- | --- |
| Canvas | `#eef2f6` | 페이지 배경 |
| Surface | `#ffffff` | 작업 표면 |
| Ink | `#172b45` | 제목과 핵심 텍스트 |
| Signal | `#356bb5` | 주 행동, 선택, 정보 상태 |
| Success | `#50bd8c` | 정상, 완료, 키보드 포커스 |
| Danger | `#d15e4d` | 오류, 삭제, 점검 필요 |

다크 테마는 동일한 의미를 유지하면서 명도만 조정합니다. Signal과 Success를 장식 목적으로 넓게 사용하지 않습니다.

## 타이포그래피

- 기본: `Noto Sans KR`, `Pretendard`, `Segoe UI`, sans-serif
- 데이터 및 시스템 레이블: `IBM Plex Mono`, `SFMono-Regular`, `Consolas`, monospace
- 제목 자간은 `-0.04em`보다 좁히지 않습니다.
- 본문은 12–14px, 행간 1.7–1.85, 읽기 폭 45–75ch를 권장합니다.
- 모노스페이스는 상태, 버전, 인덱스, 코드처럼 데이터 성격이 있는 정보에만 사용합니다.

## 형태와 깊이

- 입력과 작은 버튼: 8px 반경
- 카드와 사이드바: 14px 반경
- 대표 히어로: 24px 반경
- 일반 작업 표면은 선으로 구분하고, 중요한 대표 표면 하나에만 부드러운 그림자를 사용합니다.
- 테두리와 큰 그림자를 한 카드에 동시에 강조하지 않습니다.

## 레이아웃

- 데스크톱: 210px 내비게이션 레일 + 유연한 콘텐츠 영역
- 최대 콘텐츠 폭: 1440px
- 1080px 이하: 내비게이션을 상단 그리드로 전환
- 760px 이하: 주요 레이아웃을 한 열로 전환
- 480px 이하: 버튼과 색상 샘플을 터치 친화적으로 재배치

## 컴포넌트 규칙

### Button

- `primary`: 화면의 주요 완료 행동 하나에 사용
- `secondary`: 취소, 이전, 보조 행동
- `danger`: 삭제와 되돌리기 어려운 행동
- disabled 상태는 흐리게 표현하되 텍스트를 유지

### Field

- placeholder가 label을 대신하지 않는다.
- 오류 메시지는 문제와 해결 방법을 함께 설명한다.
- 도움말은 입력값의 형식이나 결과를 설명할 때만 사용한다.

### StatusBadge

- 점 색상과 상태 텍스트를 함께 사용한다.
- `ready`, `pending`, `danger`는 의미가 다른 상태이며 장식용 변형이 아니다.

### Empty state

- 무엇이 없는지 설명한다.
- 사용자가 다음에 할 수 있는 행동을 하나 제공한다.
- 실제 오류를 빈 상태처럼 숨기지 않는다.

## 접근성 완료 기준

- 모든 기능을 키보드로 사용할 수 있다.
- 포커스 표시가 배경과 충분히 구분된다.
- 아이콘 단독 버튼에 `aria-label`이 있다.
- 상태와 오류를 색상만으로 전달하지 않는다.
- 축소 동작 설정에서 불필요한 애니메이션을 제거한다.
- 320px 화면에서 가로 스크롤이 발생하지 않는다.
