# UI 완료 체크리스트

## 구조

- [ ] 사용자가 첫 화면에서 현재 위치와 다음 행동을 찾을 수 있다.
- [ ] 제목 계층이 DOM 순서와 시각적 순서에서 일치한다.
- [ ] 제품 전용 로직과 공통 UI 컴포넌트가 분리되어 있다.

## 브랜드

- [ ] 지정된 로고와 파비콘을 사용했다.
- [ ] 로고의 비율과 원본 색상을 변경하지 않았다.
- [ ] 색상과 간격은 디자인 토큰을 사용했다.

## 상태

- [ ] loading, empty, error, disabled 상태가 있다.
- [ ] 상태를 텍스트와 함께 표현했다.
- [ ] 오류에 사용자가 취할 수 있는 복구 행동이 있다.

## 접근성

- [ ] 키보드 포커스가 항상 보인다.
- [ ] 아이콘 버튼에 접근 가능한 이름이 있다.
- [ ] 레이블 없는 입력 필드가 없다.
- [ ] reduced-motion 설정을 존중한다.

## 반응형과 검증

- [ ] 1440px, 1080px, 760px, 390px 화면을 확인했다.
- [ ] 320px 이상에서 가로 스크롤이 없다.
- [ ] 실제 한국어 데이터에서 잘림이나 겹침이 없다.
- [ ] `npm run build`가 통과한다.
